# Desktop icons

The SVGs in `lucide/` come from [Lucide](https://lucide.dev), commit
`1ef60af944de207e0d5176905a0759ba12e6ee8d`. Their original license is in
`lucide/LICENSE` and is also included in the installed application.

`DesktopIcons` renders these vector assets at the requested display scale,
with separate normal, disabled, and on-accent colors.

The two disabled chevron variants keep the same Lucide paths and only replace
the stroke color for Qt stylesheet subcontrols.
